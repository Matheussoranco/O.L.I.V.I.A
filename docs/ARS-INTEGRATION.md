# ARS-Codex integration

This repository carries a pinned ARS-Codex snapshot (`0.1.28`) from
[academic-research-skills-codex](https://github.com/Imbad0202/academic-research-skills-codex).
The upstream lock and inactive-runtime notes are recorded in
`skills/academic-research-suite/manifest.json`.

## Two supported surfaces

- Native project surface: `skills/academic-research-suite/SKILL.md` is the
  single root router, with the five workflow recipes under
  `ars/*/WORKFLOW.md`.
- Codex plugin surface: `plugins/ars-codex/.codex-plugin/plugin.json` points to
  a materialized copy of that same skill. `.agents/plugins/marketplace.json`
  exposes it as the local `ars-codex` marketplace entry.

The Python adapter in `src/olivia/academic_research.py` keeps application code
and prompt recipes separate. `olivia academic "..."` prints the deterministic
route and can show the selected recipe with `--show-workflow`; it does not
silently spawn agents or upload manuscript content.

## Updating the snapshot

Install or update the global Codex skill from the GitHub repository, then
refresh the project copy and plugin bundle together. Keep the root router as
the only Codex-discoverable skill; internal workflows must remain
`WORKFLOW.md` files. Run:

```powershell
python skills/academic-research-suite/codex/scripts/ars_codex_quality_gates.py manifest --json
python skills/academic-research-suite/codex/scripts/ars_codex_quality_gates.py desktop-plugin-bundle --json
python skills/academic-research-suite/codex/scripts/ars_codex_quality_gates.py single-root-skill --json
```

The topology experiment gate is retained as upstream traceability material. It
must not be presented as a passing local experiment unless its frozen input
digests and receipts are regenerated by the upstream project.

## Safety boundary

The ARS root skill treats manuscripts, PDFs, reviewer notes, and retrieved text
as untrusted data. External uploads and network retrieval require explicit
consent. O.L.I.V.I.A. additionally keeps literature/page requests disabled by
default; use `olivia research ... --network` only when retrieval is intended.
